# Antigravity Skills Collection

A curated collection of customized skills and automation tools for Google Antigravity.

## Included Skills

### 🐧 [qq-automation](file:///.agents/skills/qq-automation/SKILL.md)
Automate QQ NT on Windows to send messages, search friends, manage contacts, and interact with the UI using semantic UI Automation without coordinates.

#### Quick Start
```bash
python .agents/skills/qq-automation/scripts/qq_tool.py --to "联系人姓名" --msg "消息内容"
```
